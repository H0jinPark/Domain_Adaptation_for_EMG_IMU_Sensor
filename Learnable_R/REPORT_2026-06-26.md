# 연구 보고서 — Learnable R for IMU 단독 크로스디바이스 UDA
**날짜:** 2026-06-26
**대상:** Samsung1(source, labeled) → Samsung2(target, unlabeled), 10종 운동 분류, IMU 단독
**핵심 질문:** 디바이스 간 IMU 축 불일치를, 수작업 정렬을 *주입하지 않고* **학습 가능한 회전 R**로 정렬하면서 정확도를 낼 수 있는가?

---

## 0. 요약 (TL;DR)

오늘 하루로 IMU 단독 라벨없는 도메인적응에서 **Target 70.86%** 를 달성했다(직전 학습가능-R 최고 34%, frozen 천장 44%). 핵심 결론:

1. **정확도의 진짜 레버는 정규화도 R 품질도 아닌 "인코더의 target 적응(CDAN)"** 이다.
2. **R 정렬의 핵심 신호는 gravity 가 아니라 on-the-fly PCA** 다 — 디바이스 shift 주성분이 중력축 둘레의 yaw(X↔Y 스왑)인데 gravity 는 이를 원리적으로 못 본다.
3. **R 을 SO(3) 로 파라미터화**하면 det 붕괴·NaN·MSE shrinkage 가 구조적으로 사라져 학습이 안정된다.
4. 최종 레시피 = **on-the-fly PCA prior(R 정렬) + JOINT CDAN(인코더 적응)**. PCA 가 R 을 라벨·주입 없이 X↔Y 스왑으로 자력 정렬(∠→perm 24°)한 채, CDAN 이 인코더를 적응시켜 frozen 천장(44%)을 +28%p 돌파.

## 1. 배경과 출발점

- **데이터:** EMG 2ch(1000Hz) + IMU 3ch(100Hz, 중력 포함 raw accel). 디바이스 교체로 IMU 축 순서·부호가 달라 domain shift 발생.
- **정규화 옵션:** `preprocessed_MM_raw_isotropic`(세션별 단일 scalar 정규화, **중력 DC·회전구조 보존** → R 식별 가능). zscore(`preprocessed_MM_raw`)는 분류엔 좋지만 중력·회전구조를 파괴해 R 식별 불가.
- **출발 가설(사용자 다이어그램):** 통합 손실
  ```
  L_total = L_cls_source
          + λ_da   · L_domain(source, R(target))      # 도메인 적대 정렬
          + λ_g    · L_gravity = ‖R g_t − g_s‖²        # 중력 정렬(pitch/roll)
          + λ_rot  · L_rotation = ‖RᵀR−I‖² + |det−1|²   # proper rotation
          + λ_cons · L_consistency                      # target 예측 안정화
  ```

## 2. 실험 연대기와 발견

### 2.1 DANN 통합손실 (1차) — 이상적 R, 그러나 불안정
- 구현: `LearnableRDANN`(IMUOnlyBackbone + label head + plain DANN 판별기) + 통합손실, two-phase(P1 source-only → P2 인코더 freeze, R+판별기 학습).
- 결과(isotropic, seed1, freeze): **Target 34.38%**, 학습 R 이 수작업 `R_permutation` 과 **geodesic 17.9°** = **X↔Y 스왑 + Z 반전을 라벨·분석 없이 자력 발견**.
- 문제: **불안정** — P2 에서 R 이 28에폭 정체(2~3%)→급반등(34%)→후반 감쇠(21%). 이상적 R 이 안정점이 아니라 **transient** 였다.

### 2.2 천장 분리진단 — frozen 인코더가 ~44% 천장
- 저장된 frozen 인코더에 R 만 갈아끼워 측정: identity 11%, kabsch 20%, **learned 34%**, permutation 41%, gravity 43%, **pca 44%(최고)**.
- 결론: **어떤 R(완벽 포함)을 줘도 frozen 인코더는 ~44%가 천장.** 학습 R(34%)은 순수기하 pca(44%)보다도 낮았다.

### 2.3 정규화 가설 검증 — 정규화는 레버가 아니다
- 사용자 가설: "예전 75% vs 지금 차이는 정규화뿐."
- 구현·검증: post-R 정규화(instance/batchnorm), AdaBN. 천장테스트 결과 **none 41% / instance 42% / batchnorm 40% / AdaBN 37.5%** — 정규화 레이어로는 천장이 안 오름.
- 결론: 진짜 차이는 정규화가 아니라 **인코더 적응 여부**.

### 2.4 "75%" 의 정체 규명 — EMG 가 주력, 진짜 레버는 인코더 적응
- 사용자 지적("source-only 였다, 차이는 EMG 뿐")을 EMG ablation 으로 검증:
  - `mm_no_da_seed42`(MM=EMG+IMU, source-only) + acc_dtw 하네스 + pca R → **75.81% 재현**.
  - **EMG=0 ablation: 75.81% → 25.50%** (−50%p). EMG 가 분류 주력 신호.
- 동일 pca 정리: **MM source-only 75.8%(EMG주력) / IMU단독 source-only 51.6% / IMU단독 CDAN 76.0%(인코더 적응이 EMG 자리 메움).**
- 결론: **인코더의 target 적응(CDAN)이 +24%p(51.6→76)를 만드는 핵심 레버.** freeze 는 이걸 못 쓴다.

### 2.5 R 궤적·gradient 진단 — 적대가 카오스의 원흉
- 도구 추가: **에폭별 R 출력**(∠fromI, ∠→perm[진단 watch-only, 알고리즘 사용금지], 행렬) + **R-gradient 항별 분해**(∂R + 쌍별 cosine).
- 발견:
  - 이상적 R 은 **attractor 가 아니라 transient**(통과만 하고 다른 곳에 수렴), **seed 의존**(seed1→17.9°, seed0→63°).
  - **freeze-P2 는 카오스** — 같은 seed·config 인데 CUDA 비결정성만으로 30.6% vs 0.8%. ∂R cos 가 매 에폭 ±0.8 요동(gravity↔consistency 정면충돌).
  - **원인: 적대(DANN)가 gravity 를 ~10:1 로 압도** — 비유일(여러 R 이 판별기 속임) + 재학습 표적 → R 표류.
- 사용자 통찰 확인: **"phase 분리 = 인코더 과적합"** 도 맞음(P1 이 source 96% 과특화 → frozen 천장↓+정렬불가).

### 2.6 물리 prior 설계 — gravity vs on-the-fly PCA
- **원칙 명확화:** "먼저 최적 R 풀어 고정주입(캘리브레이션) = **금지**", "매 배치 물리량을 계산해 손실로 반영(physics-informed) = **허용**". R 은 **항상 항등에서 출발**(초기화 주입 아님).
- gravity: pitch/roll 2 DOF, **yaw盲**(Rg=g라 중력축 둘레 회전 불가시) → 우리 shift 주성분 X↔Y 를 못 잡음.
- **on-the-fly PCA**: 매 배치 모션 공분산 주축(`pca_frame`)을 구해 `L_pca = ‖R Ft − Fs‖²` 로 정렬. 수평 모션구조로 **yaw 관측 가능**. 부호는 모션 왜도로 고정.

### 2.7 SO(3) 파라미터화 — det 문제 근본 해결
- 반복된 det 문제(JOINT NaN det→0, PCA MSE shrinkage det→0.6) 해결: `LearnableR(mode="so3")` — R 을 so(3) 3-파라미터의 행렬지수(`so3_exp`, Rodrigues)로 둠. **R 이 항상 det=+1·RᵀR=I** → det 붕괴·NaN·shrinkage 구조적 불가, L_rotation 자동 0.

### 2.8 비교 실험 (freeze, 적대 off, SO(3), 순수 물리구동)
| prior | Target best | ∠→perm(최종) | 수렴 |
|---|---|---|---|
| gravity-only | 22.67% | 58° (고정) | 안정 |
| **PCA-only** | **42.67%** | **159°→24° 단조** | **안정·단조** |

- **gravity 는 ∠→perm 58°에서 멈춤** = yaw盲 데이터로 증명(yaw 방향 gradient 0이라 초기값에 머묾).
- **PCA 는 X↔Y 스왑 자력 발견**(∠→perm 24°), Target 거의 2배. **frozen 천장(44%)에 사실상 도달(42.67%)** — 이 인코더에서 R 최선.

### 2.9 ★ 돌파 — PCA prior + JOINT CDAN
- 세팅: `--domain cdan --lambda_da 1 --lambda_g 0 --lambda_pca 1 --lambda_cons 0 --post_r_norm batchnorm --epochs 60 --grad_clip 5`(JOINT).
- **결과: Target best 70.86%** (frozen 천장 44%를 +28%p 돌파, 고정PCA+CDAN 참고값 76% 거의 따라잡음).
- 메커니즘 완벽 작동:
  - **PCA 가 R 을 ∠→perm 24°(X↔Y스왑+Z반전)에 안정 고정**(det 1.000 내내).
  - **CDAN 이 인코더를 target 적응**(Dacc 74→51% 적대평형 도달).
  - **역할 분리**(PCA→R 기하정렬, CDAN→인코더 도메인적응) → 카오스 0·NaN 0(SO(3)+grad_clip5+결정적 PCA).
- Shift 60%+ → **12.88%**(src 83.7/tgt 70.9), 도메인 갭 거의 닫힘.
- 한계: 후반 Target 50~70% 노이즈(best-ckpt 가 70.86 낚음), 단일 seed.

## 4. 결론과 기여

1. **방법론:** 수작업 축정렬을 **on-the-fly physics-informed prior 로 학습하는 R**(주입 0, 항등 출발)로 대체. PCA prior 가 디바이스 축 permutation(X↔Y)을 라벨없이 자력 발견.
2. **핵심 인사이트:** (a) 정확도 레버 = 인코더 적응(CDAN), (b) R 정렬 신호 = gravity 아닌 PCA(yaw 관측), (c) SO(3) 파라미터화로 안정성 확보, (d) 역할 분리(PCA→R, CDAN→인코더)로 카오스 회피.
3. **성과:** IMU 단독·라벨없는 크로스디바이스 UDA 에서 **Target 70.86%**(고정-PCA+CDAN 76% 급), 그것도 **해석가능한 학습 R** 로 달성.
